SAVR RECOMMENDED GTA SETTINGS

The installer resolves Windows' real Documents known folder, including OneDrive
redirection, backs up the active GTA settings, and installs GameUserSettings.ini.

For a manual installation:

1. Close GTA San Andreas Definitive Edition.
2. Press Win+R, enter shell:Personal, and press Enter.
3. Open:
   Rockstar Games\GTA San Andreas Definitive Edition\Config\WindowsNoEditor
4. Back up the existing GameUserSettings.ini.
5. Copy this GameUserSettings.ini into that folder.

The tested baseline enables Free Aim and uses the VR-oriented graphics and
gameplay settings used to validate this release. The installer also leaves a
GameUserSettings.SAVR-recommended.ini recovery copy beside the active file.
